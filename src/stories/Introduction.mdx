# slopdock design system

The look of slopdock, shared with the other apps it hosts: shadcn/ui (radix-nova style),
a neutral OKLCH palette in light and dark, Geist, and a handful of blocks built on top.

- **Foundations**: colours, type, radius. In the UI chrome colour means status (`--tone-*`); the only other hue is
  `--brand`, each app's accent. Charts have their own eight series colours (`--chart-1…8`).
- **Blocks**: app shell (sidebar → sheet on phones), status dots/pills, stat tiles (with sparklines), empty state, data
  table (table on desktop, cards on phones), charts.
- **Examples → App**: a whole app made only from these pieces. Try the Phone stories and the Theme / Brand toolbar.
- **Primitives**: the shadcn components exactly as slopdock uses them.

## Use it in an app

Components are **copied into the app** (shadcn registry), not installed as a package: no private npm, no build-time
dependency on this repo. This site serves the registry at `/r/{name}.json`.

Needs React 19 and Tailwind 4 (`@tailwindcss/vite`), and an `@/` alias to `src/`. Then add to `components.json`:

```json
{
  "style": "radix-nova",
  "tailwind": { "css": "src/index.css", "baseColor": "neutral", "cssVariables": true },
  "aliases": { "components": "@/components", "ui": "@/components/ui", "lib": "@/lib", "hooks": "@/hooks", "utils": "@/lib/utils" },
  "registries": { "@slopdock": "https://familien-berge.github.io/design-system/r/{name}.json" }
}
```

```sh
pnpm dlx shadcn add @slopdock/starter       # theme + every primitive + every block
pnpm dlx shadcn add @slopdock/data-table    # or one item and what it needs
```

`src/index.css`:

```css
@import "tailwindcss";
@import "./theme.css";

:root { --brand: #3d5afe; --brand-foreground: #fff; } /* optional app accent */
```

Wrap the app in `ThemeProvider` (next-themes: `attribute="class"`, `scriptProps={{ type: "application/json" }}`)
and `TooltipProvider`, and add `<Toaster />`. Put this in the app's `<head>`, or dark-mode users see a light flash on
load (next-themes' own script never runs in a client-rendered app):

```html
<script>
  try {
    var t = localStorage.getItem("theme") || "dark";
    if (t === "system") t = matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light";
    document.documentElement.classList.add(t);
    document.documentElement.style.colorScheme = t;
  } catch (e) {}
</script>
```

Norwegian app? Wrap it in `<LabelsProvider labels={nb}>` (`@slopdock/labels`): close buttons, empty and error
states, the sort picker and the theme toggle then speak Norwegian.

Forms: `FormDialog` (a bottom sheet on phones; only the body scrolls) with `Field` rows, `ConfirmDialog` before
deleting, `DataTable`'s `loading` / `error` while data is on its way. Dates: a plain `<Input type="date">` — the
theme sets `color-scheme`, so the native picker follows light/dark.

`AppShell`'s `linkComponent` must pass its other props on to the `<a>` (active row and badges depend on them).

Small inline links (a commit sha, a URL, an icon link) get `tap-target`: a 24px+ hit area on touch screens from an
invisible `::after`, so nothing moves. Don't use it on elements that already draw with `::after`.

## Charts

Recharts 3 through `@slopdock/chart` (shadcn's chart API: `ChartContainer`, `ChartTooltipContent`,
`ChartLegendContent`) and `@slopdock/chart-kit` (the house conventions). No per-app chart theme needed:

- **Colours**: `seriesConfig({ fuel: "Drivstoff", service: "Verksted" })` gives each series the next `--chart-N` in key
  order, available as `var(--color-fuel)` inside the chart. List every series the chart can show, once, so hiding one
  never repaints the rest. A grey "Other": `{ other: { label: "Annet", color: "var(--muted-foreground)" } }`.
- **Marks**: spread `chartDefaults.grid / xAxis / yAxis / bar / segment / segmentTop / line / area`: 24px-max bars with a
  4px rounded end, 2px gaps between stacked segments, 2px lines, horizontal hairlines only.
- **Size** with classes, not pixel props: `<ChartContainer className="aspect-auto h-56 md:h-72">`.
- **Numbers**: `@slopdock/locale-format` (`formatCompact` for ticks, `formatCurrency` / `formatNumber` / `formatDate` for
  tooltips and tables), nb-NO by default.
- **Accessibility**: wrap the chart in `ChartCard` with `table={<ChartTable … />}` — the chart/table switch is how a
  screen-reader or colour-blind reader gets the exact numbers. A legend for two or more series, none for one.
- **Don't**: two y-axes (make two charts), status tones as series colours, series colours on text.
- Keep the Recharts code in a lazy-loaded component so it stays out of the first page load. `Sparkline` (plain SVG) and
  `StatTile`'s `trend` don't load Recharts at all.

Migrating: kjoretoylogg's `--series-1…5` are now `--chart-1…5` (same values); ha-load-balancer's `--good`, `--warning` and
`--critical` map to `--tone-green`, `--tone-amber` and `--tone-red`.

**Updating**: re-run `shadcn add @slopdock/<item> --overwrite` and review the diff; local changes are yours to keep.
Versions, pinning and what changed: README and CHANGELOG in the repo; `head -1 src/theme.css` shows an app's version.

## Where things live

- Source: [Familien-Berge/design-system](https://github.com/Familien-Berge/design-system). Every file in `src/`
  (theme, `components/ui` primitives, `lib`, `hooks`, blocks in `components`) is one registry item.
- slopdock is a consumer like the others: change a component here, then `shadcn add --overwrite` it there.
- `pnpm registry` regenerates `registry.json` and `public/r`; pushing to `main` deploys this site.
